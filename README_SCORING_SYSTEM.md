## 🎯 核心功能

### 五维度评分体系
```
┌─ 咖啡液匹配 (25%)    ─→ 豆种、研磨度、体积比对
├─ 辅助液匹配 (25%)    ─→ 液体、体积比对（带容错）
├─ 小料匹配 (10%)      ─→ 指定小料、属性标签检查
├─ 总量匹配 (25%)      ─→ 总体积比对（带容错）
└─ 杯子适配 (15%)      ─→ 填充率评估

↓ 加权聚合 ↓

finalScore = 0-100
```

```

40-59    → Poor      (不合格)  😠 反馈: 不满意
< 40     → Terrible  (糟糕)    😤 反馈: 很不满意
```

## 💻 代码示例

### 完整监听示例
```csharp
using InnsmouthCafe.Data;
using InnsmouthCafe.Managers;
using UnityEngine;

public class GameFeedback : MonoBehaviour
{
	void OnEnable()
	{
		ScoringManager.Instance.OnScoringComplete += OnScored;
	}

	void OnDisable()
	{
		ScoringManager.Instance.OnScoringComplete -= OnScored;
	}

	void OnScored(CoffeeScoringData score)
	{
		// 1. 显示分数
		Debug.Log($"最终得分: {score.finalScore:F1}/100");
		Debug.Log($"品质等级: {score.qualityLevel}");

		// 2. 处理溢出
		if (score.hasOverflow)
		{
			Debug.Log($"⚠️ 咖啡溢出！理智损失: {score.overflowSanityLoss}");
			// SanityManager.ReduceSanity(score.overflowSanityLoss);
		}

		// 3. 播放反馈动画
		switch (score.feedbackLevel)
		{
			case 2: /* 播放满意动画 */ break;
			case 1: /* 播放一般动画 */ break;
			case 0: /* 播放不满意动画 */ break;
		}

		// 4. 计算奖励
		float reward = score.finalScore > 80 ? 100 : 50;
		Debug.Log($"获得金钱: {reward}");
	}
}
```
